پتشاپ خوشمزه — نسخه ۱۸۸ محصولی، تکمیل تصویر محصولات جدید N&D

تصاویر اصلی محصولات ۲۵۱ تا ۲۵۹ با فایل‌های دریافت‌شده از مشتری جایگزین شدند.
تصاویر در کارت صفحه اصلی، داخل صفحات اختصاصی، جستجو و داده‌های تصویر ترب و ایمالز همگام‌سازی شدند.
۹ پیام قدیمی «تصویر موقت» که در صفحات ۲۳۱، ۲۳۳، ۲۳۴، ۲۳۷، ۲۴۰، ۲۴۱، ۲۴۲، ۲۴۸ و ۲۴۹ جا مانده بود پاک شد؛ فایل عکس این محصولات قبلاً واقعی بود.
برای هر ۲۹ محصول جدید N&D، متن جایگزین عکس (Open Graph image alt) که اشتباهاً نام Royal Canin داشت اصلاح شد.
قیمت‌ها، تعداد ۱۸۸ محصول، نام‌ها، کد محصول، وضعیت سفارش، پرداخت، سبد و فاکتور بدون تغییر ماند.

فایل ZIP کامل را می‌توان روی مخزن GitHub Pages جایگزین کرد؛ تا بارگذاری نشود، نسخه آنلاین تغییر نمی‌کند.
