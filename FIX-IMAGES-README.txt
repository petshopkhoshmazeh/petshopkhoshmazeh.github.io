پتشاپ خوشمزه - نسخه اصلاح ماندگار نمایش عکس‌ها
۱) همه عکس‌های کم‌حجم ۱۲۶ محصول در خود فایل index.html پشتیبان دارند.
۲) اگر عکس جداگانه توسط GitHub Pages یا Cloudflare در دسترس نبود، عکس واقعی محصول باز هم در صفحه اصلی نمایش داده می‌شود.
۳) وقتی عکس جداگانه در دسترس باشد، کیفیت بالاتر آن خودکار جایگزین عکس کم‌حجم می‌شود.
۴) صفحه اصلی و کد پرداخت و فاکتور حفظ شده‌اند. صفحات اختصاصی از قبل عکس توکار دارند.
۵) این فایل ZIP را فقط دانلود نکنید: محتوا را در مخزن GitHub Pages منتشر کنید؛ ZIP به‌تنهایی سایت را تغییر نمی‌دهد.
۶) پس از انتشار، کش Cloudflare را پاک و تصویر را روی اینترنت موبایل بازآزمایی کنید.
۷) محدودیت: وضعیت واقعی دسترسی فایل‌ها و کش CDN فقط پس از انتشار زنده مشخص می‌شود.
۸) چنانچه نسخه قدیمی آنلاین نمایش داده شود، این اصلاح هنوز روی سایت اجرا نشده است.
