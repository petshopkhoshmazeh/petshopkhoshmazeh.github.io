پتشاپ خوشمزه — راهنمای آماده‌سازی فهرست محصولات برای ترب و ایمالز
تاریخ: ۲۹ اکتبر ۲۰۲۶
دامنه: https://petshopkhoshmazeh.ir

خلاصه اطلاعات:
- ۱۲۴ محصول با تصویر و صفحه مستقل
- ۴۴ محصول موجود (instock)، ۷۱ محصول قابل پیش‌سفارش از استانبول (preorder)، ۹ محصول ناموجود (outofstock)
- قیمت‌ها در فیدهای CSV و JSON بر حسب تومان، و در فیدهای XML در g:price بر حسب ریال (IRR) درج شده‌اند؛ تبدیل: هر تومان = ۱۰ ریال
- «قابل پیش‌سفارش» با «موجودی آماده ارسال» متفاوت است؛ در فید XML نیز جدا مشخص شده است.

نکته بسیار مهم فنی:
سایت فعلی با GitHub Pages (هاست استاتیک) ساخته شده است. در نتیجه درخواست HTTP POST و اعتبارسنجی JWT برای API رسمی نسخه ۳ ترب یا احراز هویت وب‌سرویس رسمی ایمالز روی این هاست قابل پیاده‌سازی مستقیم نیست.
این ZIP یک خروجی ایستا (XML/CSV/JSON) آماده انتشار و صفحه قابل خزش تولید می‌کند؛ «اتصال فعال و تایید شده رسمی API» نیست.
مستندات رسمی ترب اعلام می‌کند فروشگاه‌های کوچک پس از ثبت‌نام معمولاً خزش می‌شوند و لزوماً نیازی به API بزرگ‌فروشگاه‌ها ندارند:
https://github.com/torob/Torob-Sync
برای API رسمی نسخه ۳، باید یک سرور/تابع پردازش POST به همراه تایید JWT ترب فراهم شود:
https://github.com/torob/Torob-Sync/blob/main/product_api_v3.md

مراحل پیشنهادی:
۱) محتویات ZIP را مستقیماً در ریشه مخزن GitHub Pages قرار دهید و Deploy کنید.
۲) URLهای فوق را بعد از انتشار در مرورگر بررسی کنید.
۳) از پنل فروشندگان ترب و پشتیبانی ایمالز بخواهید سایت، sitemap و فیدهای این ZIP را بررسی و روش سازگار با حساب شما را تایید کنند.
۴) پذیرش و انتشار نهایی محصولات در ترب و ایمالز، نیازمند تایید/خزش توسط این سرویس‌هاست و از طریق ساخت فایل به‌تنهایی تضمین نمی‌شود.
۵) با هر تغییر قیمت یا موجودی، داده‌های سایت و list.json را یکسان به‌روزرسانی و فایل‌های فید را با python3 scripts/generate_marketplace_feeds.py از نو بسازید و مجدداً منتشر کنید؛ به‌روزرسانی لحظه‌ای خودکار روی هاست استاتیک انجام نمی‌شود.

کنترل کیفیت اجراشده:
- وجود صفحه محصول و عکس، شناسه یکتا، یکسان بودن قیمت و عنوان فهرست با متادیتای محصول برای همه ۱۲۴ کالا بررسی شد.
- توضیح قدیمی قیمت محصول ۱۶۶ در صفحه و نسخه موجود در صفحه اصلی اصلاح شد: ۱۳٬۴۰۰٬۰۰۰ تومان.
- فهرست HTML ایمالز که شمارش و قیمت‌های قدیمی داشت از اول با هر ۱۲۴ محصول ساخته شد.
- ۲۶ تصویر کم‌ابعاد با حفظ طرح موجود به اندازه حداقل ۹۰۰ پیکسل در هر ضلع تغییر اندازه داده شدند؛ افزایش اندازه به معنی بازیابی جزئیات واقعی عکس نیست. بهتر است در آینده اصل عکس‌های باکیفیت‌تر جایگزین شوند.
